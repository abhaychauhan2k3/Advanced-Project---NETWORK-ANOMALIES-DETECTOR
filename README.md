# Advanced-Project---NETWORK-ANOMALIES-DETECTOR
It is a type of Intrusion Detection System by training a ML model - which is capable of detecting malicious activities on Manual testing as well as on real-time testing using Tshark.
# WorkFlow of the project : 
Selection of appropriate Dataset --> Cleaning and preprocessing of the dataset --> spliting data to train-test split --> picking up apropriate ML algorithm --> training the model --> evaluation --> deployment using Streamlit --> implementing Tshark for real-time testing feature.

# what I have done:
-> Dataset used - CICIDS2017
-> ML algo used - Random Forest Classifier
(these two things were picked up by reading several Research papers and by exploring different different platforms)
-> Model Deployment - for model deployment Streamlit is used (UI)
